There is no default key for brush size: resize with a right-click drag, or assign a key yourself if your version lists one.

Create your own hotkeys: Settings › Keyboard Shortcuts… › Edit

  1. Click Settings (cog in the top-left bar, next to Patients and Sessions).
  2. Choose Keyboard Shortcuts…: the list shows each action and its current key.
  3. Select the action, click Edit, press the new key or combination, then confirm.
  4. Avoid keys already taken: F1–F4, W, 3, 4, =, C, X, F, E, M, the arrows, Ctrl+Z / Y and Ctrl+Shift+B.

The guide gives only the menu path; steps 2–4 describe the dialog as it usually works, so wording may differ slightly in 7.4.3.

The tools used most for target and OAR contouring, with how each works.

Set up your workspace

  • Toolbar: cog on the right of the toolbar → green + to add, red – to remove, drag to reorder tools, extensions and workflows. Saved for your next login.
  • Mode Tools: settings option in the panel → add or remove contouring tools and workflows.
  • Contour settings: colour, line width, name, Fill 0–100 % (good for checking Hard Edge results) and range lock (bone, tissue, air presets or custom HU). Set range lock back to None after use.
  • Contour cog menu: rename, erase, delete, clone, statistics, Localize to Contour Centroid, Lock Contour (protects previous-treatment volumes).
  • Series to Contour must be the planning CT: structures attach to it.
  • Colour: click the grey-scale bar to change the colour map for fusions and PET.

Sessions, saving and recovery

Saving structures is not the same as saving a session. Follow your local work instruction for saving sessions.

Saving

  • The blue floppy in the contour list saves structures to a dataset. It does not save the session.
  • Contour names in italics are empty; white names contain contours.
  • Avoid several open sessions for one patient: it causes confusion.
  • Use Session Notes to flag issues for RTs and planners.

Recovery and auto-deletion

  • Autosave recovery: Import › Browse… → your MIM recovery share (ask your MIM SME or physics) → your username › RECOVERY › RTAUTOSAVE → select all RTst files → import to MIMpacs → reopen with Add All Data.
  • In the guide's set-up, data not opened for 35 days are deleted automatically. To keep a case, save a session called Keep, or anonymise it with Case in the patient name (teaching).

Recovery paths and deletion rules are local configuration. Check with your MIM SME.
